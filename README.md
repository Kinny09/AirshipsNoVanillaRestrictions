# AirshipsNoVanillaRestrictions
A mod for the 2D steampunk strategy game Airships: Conquer the Skies that removes the placement restrictions on all the vanilla modules in the game.

## Links
The game may be found here: https://store.steampowered.com/app/342560/Airships_Conquer_the_Skies/  
The mod is not meant to be installed via the git page, if you want to install it, please install via the steam workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=2353212844
